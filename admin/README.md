# Denish Admin Panel (Vite)

This is the converted React + Vite version of the Denish Admin Panel. It provides a faster development experience and runtime performance compared to the previous Next.js setup.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- Real-time Dashboard
- Order Management
- Vendor Management
- Driver Management
- User Management
- Dispute Resolution
- Payments & Commissions
- Content Management (Banners & Promos)

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Lucide React (Icons)
- Framer Motion (Animations)
- Recharts (Charts)
- Zustand (State Management)
- Axios & Fetch (API)
